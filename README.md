# adana-skolyoz-merkezi
Adana Skolyoz Merkezi web sitesi. Schroth Terapisi, skolyoz değerlendirmesi, postür analizi ve kişiye özel egzersiz programları sunan fizyoterapi temelli omurga sağlığı platformu. Adana’da skolyoz ve postür bozuklukları için Schroth terapisi ve fizyoterapi temelli egzersiz hizmetleri sunan web sitesi.
